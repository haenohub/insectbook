# Hallmark 디자인 개선

공식 스킬: https://github.com/Nutlope/hallmark/tree/04977e15f3dfd6ee4b74c887dac3eb52665d6c92/skills/hallmark

Hallmark 2.0.0의 기존 앱 전면 개선 절차를 적용했습니다. 브랜드 색과 한국어 서체가 이미 정해져 있어 `scaffold --brand --redesign full --scope app`으로 시작했습니다.

## 보존한 내용

- 721장 손그림과 원문 자료. 이미지 생성은 중단 상태입니다.
- 이름·학명·과·속·특징 검색, 복수 필터, URL 상태, 관찰함과 배틀 기록.
- 선택·랜덤 매칭, 모든 능력치와 배틀 계산 규칙.
- 기존 링크 2/2, 입력 항목 5/5, 핸들러 64/64.
- 본문 16px 이상, 보조 정보 14px 이상.

## 바꾼 표현

- 영어 대문자 장식 문구, 별 모양 문자, 가짜 좌표, 스티커와 종이 테이프 장식을 제거했습니다. 한국어 본문과 실제 분류·생태 정보는 보존했습니다.
- `관찰 정보 · 국립수목원`은 `관찰 정보 제공: 국립수목원`으로 바꿨습니다. 하단의 게임 재해석 안내 문장은 그대로 두었습니다.
- `EXPLORER 01/02`, `WINNER`, `ROUND`, `READY?`, `CRITICAL`을 같은 뜻의 한국어 상태로 표시합니다.
- 곤충 탐험하기, 나의 관찰함, 지난 대결 기록의 개수는 제목 옆으로 옮겼습니다. 정확한 제목 문자열은 7/10이며 나머지 3개는 이 변경으로 기록했습니다. 제목 자체와 개수 정보는 남아 있습니다.
- 이름을 먼저, 과와 학명을 아래에 배치했습니다. 긴 이름은 카드의 title과 상세 보기에서 확인할 수 있습니다.
- 모바일 필터를 열면 배경을 비활성화하고 포커스를 패널 안에 유지합니다. Escape로 닫으면 기존 버튼으로 돌아갑니다.
- JavaScript를 끈 환경에는 도감 원문으로 이동하는 안내를 제공합니다.

## 검증

Hallmark의 원본 sloplint로 3개 화면을 320, 375, 414, 768, 1024, 1280, 1440, 1920px에서 검사했습니다. 필수 위반 0, 미해결 Reflex 0, 경고 0입니다. 세부 기록은 audit.json에 있습니다.

두 화면의 큰 그림 선택 영역은 일반 버튼 높이 기준(39b)보다 넓은 터치 영역을 유지했습니다. 기존 선택 피드백(16)은 상세 대화상자 뒤로 선택 트레이가 가려질 때에도 확인할 수 있도록 보존했습니다. 숫자 관련 Finish 검사(F6)는 표본 번호와 능력치의 tabular-nums, 일반 문장 제목의 오탐을 기록했습니다.

별도 문맥의 디자인 검토가 발견한 모바일 필터 포커스와 문장 붙음 2건은 수정 후 재검토에서 모두 해결됐습니다.

단위 테스트 10개, 브라우저 테스트 8개, 이미지와 원문 파일 해시 721건 검증 및 `/insectbook/` 빌드가 통과했습니다. 기존 테스트는 변경하지 않았고 키보드 필터 및 스크립트 비활성 안내 테스트를 추가했습니다.

## 비교와 자료

작업 환경의 `.hallmark/compare.html`에서 공식 렌더 도구의 전후 비교를 볼 수 있습니다. 스크린샷과 원본 기록은 `.hallmark/before/`, `.hallmark/shots/`에 있으며 Git에는 포함하지 않습니다.

이 페이지는 사용자의 기존 그림만 사용해 대체용 이미지나 비어 있는 자료 슬롯이 없습니다. 추가로 필요한 이미지 자료도 없습니다.
